# IMDB Sentiment Analysis

## Deskripsi

Proyek Machine Learning untuk mengklasifikasikan sentimen ulasan film IMDB menjadi positif atau negatif menggunakan Python.

## Dataset

Dataset yang digunakan berasal dari Kaggle.

* **Train Dataset:** Link Kaggle akan ditambahkan.
* **Test Dataset:** Link Kaggle akan ditambahkan.

## File Dataset

* `train.csv`: Dataset untuk melatih model.
* `test.csv`: Dataset untuk menguji model.

## Teknologi

* Python
* Pandas
* Scikit-learn
* Machine Learning

## Cara Menjalankan

1. Unduh dataset dari Kaggle.
2. Letakkan `train.csv` dan `test.csv` dalam folder yang sama dengan source code.
3. Instal library yang diperlukan.
4. Jalankan program Python.
